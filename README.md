# 📈 Stock Alert Pro - ระบบติดตามราคาและแจ้งเตือนหุ้น Shortlist (ระดับ 1%)

ระบบ Dashboard สำหรับติดตามราคาหุ้นแบบ Real-time พร้อมฟังก์ชันจัดกลุ่ม Shortlist และระบบส่งสัญญาณแจ้งเตือนอัตโนมัติเมื่อราคาหุ้นวิ่งเข้าใกล้เป้าหมายในระยะ **1%**

---

## ✨ จุดเด่นและความสามารถของระบบ

1. **รองรับทั้งหุ้นไทยและหุ้นต่างประเทศ**
   - หุ้นไทย (SET): เช่น `PTT`, `DELTA`, `CPALL`, `BDMS`, `AOT` (ระบบจะต่อท้าย `.BK` ให้อัตโนมัติ)
   - หุ้นสหรัฐฯ (US / Global): เช่น `AAPL`, `NVDA`, `TSLA`, `MSFT`, `AMD`
   - ค้นหาแบบ Live Autocomplete อัตโนมัติ

2. **ระบบแจ้งเตือนระดับ 1% (1% Proximity Detection)**
   - คำนวณระยะห่างระหว่างราคาปัจจุบันกับเป้าหมายแบบเรียลไทม์
   - **เมื่อห่างไม่เกิน 1%**:
     - 🚨 ป้ายสถานะสีส้มอมแดงกระพริบเตือน (Glowing Pulse Badge)
     - 🔔 มีเสียงสัญญาณเตือน Chime (Web Audio Synthesizer)
     - 🖥️ การแจ้งเตือนหน้าต่างเบราว์เซอร์ (Browser Desktop Notification)
     - 🪟 Windows Desktop Toast Notification (ป๊อปอัปมุมจอด้านล่างขวาของ Windows)
   - **เมื่อแตะหรือทะลุเป้าหมาย**: แสดงสถานะ 🎯 "ถึงเป้าหมายแล้ว" (Target Reached)

3. **Dashboard ใช้งานง่าย & สวยงาม**
   - สรุปตัวเลข KPI (Shortlist ทั้งหมด, ตัวที่เข้าใกล้ 1%, ตัวที่ถึงเป้า, ตัวที่ใกล้ที่สุด)
   - กราฟแนวโน้มขนาดย่อ (Sparkline Mini Chart 5 วัน)
   - แถบเกจวัดระยะห่าง (Proximity Progress Bar)
   - บันทึกเหตุผล / Trading Notes ประกอบการตัดสินใจ
   - บันทึกประวัติการเตือนย้อนหลัง (Alerts History Log)

## 📱 วิธีเปิดใช้งานบน iPhone (ทั้ง Wi-Fi และ Cellular 4G/5G)

### 1. เข้าผ่าน Cellular 4G/5G (เปิดดูได้จากทุกที่ทั่วโลก)
ระบบมาพร้อม **Cloudflare Tunnel** อัตโนมัติ:
1. บนหน้าจอคอมพิวเตอร์ กดปุ่ม **"เปิดบน iPhone (4G/5G)"** บริเวณมุมขวาบน
2. จะมี **QR Code** และลิงก์ HTTPS แสดงขึ้นมา
3. ยกกล้อง iPhone ขึ้นมาสแกน QR Code แล้วแตะที่ป้ายเหลือง Safari ได้ทันที

### 2. เข้าผ่าน Wi-Fi เดียวกัน
พิมพ์ในช่อง Safari:
```text
http://192.168.192.118:8000
```

> **💡 แนะนำ:** เมื่อเปิดใน Safari แล้ว ให้กดปุ่ม **แชร์ (Share)** -> เลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)** เพื่อให้กลายเป็นแอปบนหน้าจอมือถือแบบเต็มจอ!

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์รัน
ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`**
> ระบบจะเปิดหน้าต่างเบราว์เซอร์ไปยัง `http://localhost:8000` โดยอัตโนมัติ

### วิธีที่ 2: รันผ่าน PowerShell / Terminal
```powershell
.\venv\Scripts\uvicorn.exe backend.app:app --host 127.0.0.1 --port 8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **`http://localhost:8000`**

## ⚙️ การตั้งค่าเพิ่มเติม (ในเมนู Settings บนหน้าเว็บ)
- **ความถี่ในการรีเฟรชราคา**: ปรับได้ตั้งแต่ทุก 5 วิ, 10 วิ, 15 วิ, หรือ 30 วิ
- **เกณฑ์เปอร์เซ็นต์แจ้งเตือน**: ปรับเปลี่ยนจาก 1.0% เป็นค่าอื่นๆ ได้ตามต้องการ
- **เปิด/ปิดเสียงเตือน**: มีสวิตช์เปิด-ปิด และปุ่มทดสอบเสียง
- **ปุ่มเปิดแจ้งเตือนบนเบราว์เซอร์**: กดปุ่ม "เปิดแจ้งเตือน" บริเวณมุมขวาบน เพื่ออนุญาตให้เบราว์เซอร์แจ้งเตือนขณะพับหน้าจอได้

## 📁 โครงสร้างโปรเจกต์
- `backend/`
  - `app.py`: FastAPI Web Server & WebSocket Engine
  - `stock_service.py`: ดึงข้อมูลราคาหุ้น Real-time และคำนวณระยะ 1%
  - `storage.py`: ระบบจัดการและบันทึกข้อมูล Shortlist
  - `notifier.py`: ระบบส่งสัญญาณเตือนไปยัง Windows Toast & Web
- `frontend/`
  - `index.html`: หน้าจอ Web Dashboard
  - `app.js`: ระบบเสียงสังเคราะห์, จัดการการเชื่อมต่อ WebSocket และ UI
  - `style.css`: ตกแต่งธีม Dark Mode การเงินระดับมืออาชีพ
- `data/`
  - `watchlist.json`: ข้อมูลหุ้นใน Shortlist ที่บันทึกไว้
  - `alerts.json`: บันทึกประวัติการแจ้งเตือน
  - `settings.json`: การตั้งค่าระบบ
